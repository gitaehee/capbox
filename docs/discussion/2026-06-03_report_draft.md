특히 바이브코딩의 효과를 설명할 때는 단순히 “AI가 코드를 작성해 주었다”가 아니라, 요구사항 분석, 설계, 구현, 테스트, 품질관리 단계에서 각각 어떤 도움과 한계가 있었는지를 중심으로 서술한다.

## 6. 추가 개선 사항: 이미지 업로드 방식 안내 보완

보고서 초안 작성 중 사용자가 이미지를 직접 파일 선택 방식으로 업로드하는 것뿐 아니라,
드래그 앤 드롭 방식으로도 업로드할 수 있으면 사용성이 더 좋아질 것이라고 판단하였다.

Streamlit의 `st.file_uploader()`는 기본적으로 파일 선택과 드래그 앤 드롭 업로드를 모두 지원한다.
따라서 별도의 복잡한 기능을 새로 구현하기보다, 사용자가 해당 기능을 쉽게 인지할 수 있도록 업로드 영역의 설명 문구를 보완하였다.

이를 통해 사용자는 파일 탐색기를 통해 이미지를 선택할 수도 있고,
이미지를 업로드 영역에 직접 드래그하여 추가할 수도 있다.

이번 수정은 기능 자체를 크게 확장한 것은 아니지만,
사용자가 기존 기능을 더 쉽게 이해하고 사용할 수 있도록 개선한 UI/사용성 개선 작업이다.
